# soci502repository
This repository contains a datastory for SOCI502. 

This project explores the changes in Métis population 
across the prairie provinces: Manitoba, Saskatchewan and Alberta
using Canadian Census data from 2016 and 2021.

The analysis begins with comparing provincial data, and will 
expand to examine trends across urban and rural communities.

**Data sources:**
- Statistics Canada, 2016 Census of Population
- Statistics Canada, 2021 Census of Population
- Census data from `cancensus` R package

**Software and packages required:**
- R and Rstudio applications
- Quarto (for reproducible reports)
- Git and Github (for version control)
- `tidyverse` (for data cleaning and manipulation)
- `cancensus` (to access census data)
- `knitr` (for creating tables)

## Repository structure:*
- milestone_1_files (beginning of my project)
- milestone_2_files (data aquision, cleaning, tests, EDA)
- scrips (final scrips)
- outputs (generated outputs and reports)

*File structure may change and final data story is in progress*
